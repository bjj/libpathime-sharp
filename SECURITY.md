# Security

Report vulnerabilities privately through GitHub's security advisories:
<https://github.com/bjj/libpathime-sharp/security/advisories/new>. Reports
get a response within a week; please do not open a public issue for anything
you believe is exploitable. Only the latest release is supported — a fix
ships as the next release.

Problems in the native library itself belong in
[libpathime](https://github.com/bjj/libpathime/security/advisories/new);
this repository is the C# binding and its packaging. When in doubt, either
works.
